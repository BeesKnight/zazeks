# Android ↔ Python model integration

## 1. Выбор формата взаимодействия

Для мобильного клиента выбрана схема **сетевого обращения к Python-сервису** (`FastAPI /model/detect`). Причины:

- Текущая модель `best.pt` (~90 МБ) обучена в формате YOLOv11 и не имеет оптимизированного TFLite/ONNX-артефакта в репозитории.
- На Android-пристройстве потребуется значительный объём памяти и GPU/NNAPI для локального инференса; перенос `ultralytics` невозможен без серьёзной доработки.
- Python-сервис уже развёрнут в backend-проекте и содержит проверенную бизнес-логику постобработки (`class_names`, выбор первой коробки и т.д.), поэтому клиенту достаточно повторить сетевой контракт.

> Если в будущем появится TFLite-модель, адаптер допускает расширение: достаточно добавить локальную реализацию, не меняя публичный API `NeuralModelBridge`.

## 2. Адаптер `NeuralModelBridge`

Файл: `android/src/main/java/com/example/zazeks/infra/ml/NeuralModelBridge.java`.

- Получает от игрового движка кадр (`GameFrame`) с JPEG-байтами.
- Отправляет multipart-запрос `file=<frame>.jpg` на `baseUrl/model/detect`.
- Возвращает `DetectionResult` с жестом и необязательным bounding box (формат полностью совпадает с Python).
- Реализован на OkHttp, чтобы использовать единый HTTP-стек и повторное подключение при обрывах.

Дополнительные DTO:

- `GameFrame` — иммутабельный контейнер для кадра (ширина, высота, timestamp, байты).
- `DetectionResult` — жест + коробка (`[x1, y1, x2, y2]`).

## 3. Тестовые сценарии

Юнит-тесты (`android/src/test/java/com/example/zazeks/infra/ml/NeuralModelBridgeTest.java`) используют `MockWebServer`, который возвращает эталонный JSON бэкенда. Проверяется, что:

1. Адаптер отправляет multipart и корректно строит имя файла.
2. Ответ разбирается в точности так же, как в Python (`gesture = "Rock"`, `bbox = [10,20,30,40]`).

Запуск: `cd android && gradle test --tests com.example.zazeks.infra.ml.NeuralModelBridgeTest`.

Для интеграционного теста «конец-в-конец» поднимите backend (`uvicorn --app-dir backend src.main:app`), затем укажите в Android `baseUrl = "http://10.0.2.2:8000/"` (эмулятор) или адрес локальной машины.

## 4. Инженерные требования

- **Внешний сервис:** перед запуском клиента необходимо запустить Python backend (`/model/detect`). Для production — разместить рядом с основным API, включив HTTPS и аутентификацию токеном.
- **Конфигурация:** `NeuralModelBridge.remoteHttp(baseUrl)` принимает URL сервиса. Храните его в `BuildConfig`/`RemoteConfig` в зависимости от окружения.
- **Сетевые ограничения:** ограничение размера кадра ≤ 1 МБ, таймауты 10–15 секунд, повторная отправка при `IOException` с экспоненциальной задержкой.
- **Fallback:** при отсутствии сети необходимо обрабатывать `IOException` и показывать пользователю подсказку (игра продолжится с ручным выбором жеста). Интерфейс `DetectionResult` допускает расширение для локальной TFLite-версии — сохраните одинаковые поля.
- **Встраивание модели:** если позже появится офлайн-режим, TFLite-файл кладётся в `android/src/main/assets/models/`. Обёртка `NeuralModelBridge` должна получить дополнительный конструктор `localInterpreter(...)` и вернуть тот же `DetectionResult`.

Документ является частью Android-инфраструктуры и должен обновляться при любом изменении контракта Python-сервиса или формате ответа модели.
